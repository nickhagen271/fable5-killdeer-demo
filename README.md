# Killdeer

A painted meadow that never ends, and a killdeer who lives in it. Every
frame aims to read as an impressionist painting — instanced brush strokes
and palette-knife dabs in world space, a screen-space painterly post stack
over them — while a real *Charadrius vociferus* (double breast band, red
orbital ring, rufous tail flash) runs, stops, tilts its head, and eats
worms. That is the whole game.

Built with TypeScript (strict), Vite, and three.js WebGPURenderer + TSL.
No external assets: every stroke shape, palette, noise and the bird itself
are generated by code. **WebGPU only** — it fails loudly with instructions
if the browser can't provide it (current Chrome or Edge work).

## Play

```
npm install
npm run dev        # http://localhost:5173
```

| Input | Action |
|---|---|
| `W A S D` or arrows | Move (the bird runs in the camera-relative direction) |
| Mouse drag | Orbit camera |
| Scroll | Zoom camera |
| `Space` | Peck (a worm within reach is eaten — the counter top-left keeps score) |
| `P` | Toggle palette (sunset / overcast) |
| `F3` | Debug HUD (fps, frame ms, strokes, worms eaten, streaming stalls, seed) |
| `?seed=N` in URL | Reproduce a specific world (terrain, flowers, worms — everything) |

Finding worms: they are small curled strokes on the ground, clustered near
bare soil patches, and deliberately a little hard to see. Within about two
meters the bird tilts its head toward the nearest one — that head-tilt is
the only hint the game gives.

Other URL switches: `?palette=overcast` boot palette, `?grade=0` disables
the final color grade, `?post=0` bypasses the painterly post stack
(debug), `?bare=1` shows the bird alone on canvas (the turnaround),
`?hud=1` forces the HUD.

## Deploy

`npm run build` produces a static `dist/` served from any static host.
`.github/workflows/deploy.yml` builds and publishes it to GitHub Pages on
every push to `main`; the Vite `base` is set to `/fable5-killdeer-demo/`
accordingly. Live URL pattern:

```
https://<owner>.github.io/fable5-killdeer-demo/
```

(For this repository: https://nickhagen271.github.io/fable5-killdeer-demo/
once Pages is enabled for the repo with "GitHub Actions" as the source.)

## Development

```
npm run typecheck   # tsc, strict, zero any
npm run shots -- --phase N [--only name] [--palette overcast] [--bare]
npm run trek        # the 2 km no-edge/no-stall gate, screenshot every 200 m
npm run forage      # the ten-worms-in-three-minutes playtest gate
npm run compare     # side-by-sides against reference/
```

The Playwright harness runs WebGPU headless on SwiftShader, so every gate
above works on a machine with no GPU. `DELTA.md` holds the per-phase
reference-delta loop; `DEVIATIONS.md` the spec deviations; `shots/` the
committed gate evidence.

## Architecture

```
src/render/   WebGPU bring-up, diagnostics, compute self-test
src/paint/    the painting: palette scripts + LUT, shared fields, post
              stack, ground strokes, grass/flower dabs, accents, wind
src/world/    terrain (CPU/GPU-twin noise), streamed groves & hedgerows,
              hill band, sky, worms, follow camera, world assembly
src/bird/     the killdeer: procedural rig, painted markings, locomotion
src/debug/    HUD
tools/        Playwright gates: shots, trek, forage, compare, probe
```
